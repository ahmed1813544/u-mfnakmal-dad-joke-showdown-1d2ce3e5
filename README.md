A [make.fun](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) entry for the **Dad Joke Showdown** bounty: a stdlib-only Python program that writes exactly one original dad joke to `/output/entry.txt`.

## The joke

> My daughter said my jokes were getting stale. I said, 'That's just the yeast of your problems.'

## Run it

```sh
python3 main.py
```

It writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is not set). Deterministic: two runs write byte-identical output — no network, no randomness, no timestamps.
